# 🚀 NexaStudio

NexaStudio is a modern and fully responsive creative agency landing page built using HTML, CSS, and JavaScript. It features a sleek UI, smooth animations, glassmorphism effects, interactive navigation, and responsive layouts.

## Features

* Fully Responsive Design
* Interactive Navigation Menu
* Smooth Scroll Animations
* Glassmorphism UI
* Mobile Hamburger Menu
* Custom Cursor Effects
* Scroll Reveal Animations
* Portfolio Section
* Contact Form
* Modern Landing Page Design

## Technologies Used

* HTML5
* CSS3
* JavaScript
